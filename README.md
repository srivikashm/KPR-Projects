Student Marks Calculator

A Python-based Student Marks Calculator developed as part of my First-Year Artificial Intelligence and Data Science coursework at KPR College.

About the Project

This project is designed to calculate a student’s academic performance based on marks obtained in five subjects. It automatically calculates the total marks, average, percentage, and pass/fail status.

Features

* Calculates total marks.
* Calculates average marks.
* Calculates percentage.
* Displays pass/fail status.
* Simple and user-friendly Python program.

Technologies Used

* Programming Language: Python
* IDE: Visual Studio Code

How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

python marks_calculator.py
